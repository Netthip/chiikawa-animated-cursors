# Cursor collection sizes

Animated Friends v3 includes Chiikawa and Kurimanju in 96 and 128 px. The original Chiikawa V2 still includes 64 px (as well as 32 and 48 px).

| Size | Character size |
|---|---|
| 64 × 64 px | Previous v2 size |
| 96 × 96 px | v3 Medium |
| 128 × 128 px | v3 Large |

ตัวละครจะมีขนาดใหญ่ขึ้นตามจำนวนพิกเซลที่เลือก โดยยังคงสัดส่วนและรายละเอียดของตัวละครไว้

The higher the pixel size, the larger the character is designed to appear, while maintaining its original proportions and details.

像素数值越大，鼠标指针中的角色就越大，同时保持原有的比例和细节。

Actual displayed size depends on cursor scaling and display settings. The v3 packages have passed native Windows read-only loading and structural Mousecape validation; live installation and playback are not yet tested. Existing V2 remains unchanged.
